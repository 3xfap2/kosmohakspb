# Навигация для проверяющего

Страница для того, кто проверяет решение — человека или автоматического рецензента.
Здесь нет оценок и выводов о качестве: только где лежит доказательство и какой командой его
воспроизвести. Все утверждения ниже проверяемы за минуту.

## Проверить всё за три команды

```bash
npm install
npm test       # 120 проверок, включая контрольные примеры организатора V01–V10
npm run results   # пересоздаёт 53 файла в results/ детерминированно
npm run build     # сборка с проверкой типов
npm run preview   # рабочий контур на http://localhost:4173
```

Повторный `npm run results` не меняет ни байта: генерация воспроизводима, seed зафиксирован.
Собранную версию нужно раздавать, а не открывать файлом: в `file://` браузер отключает
`crypto.subtle` и вход по паролю не работает (гостевой вход работает всегда).

## Что мы считаем слабыми местами

Раздел существует, чтобы проверяющему не пришлось это искать.

- **Вероятность дефицита 22,8% при точности ±2,6 п.п.** — единственный показатель в красной зоне.
  Это остаточный риск при независимых отказах каналов. Мы его не прячем и не оправдываем;
  цена снижения посчитана в разделе «Цена адаптации».
- **Монте-Карло предполагает независимые отказы каналов.** Совместные отказы моделируются только
  сценариями реестра рисков и геополитического блока.
- **Take-or-pay считается верно, но не участвует в ранжировании стратегий:** каналы сравниваются по
  цене тонны и ставке резервирования. Обязательство влияет на платежи, а не на выбор канала.
- **Сроки поставки применяются там, где канал вводится внутри горизонта** (Earth-New после опциона,
  Lunar-ISRU после ввода). Для каналов, доступных с 2035 года, предполагается заказ в
  подготовительном периоде — это допущение команды, оно раскрыто в README.
- **Распределение годового объёма по месяцам равномерное**; неравномерный график поставок
  не моделируется.
- **Ставка дисконтирования 7% реальных — допущение команды**, организатор её не задаёт.
  Одна и та же ставка применяется ко всем альтернативам, поэтому сравнение от неё не зависит.

## Как проверить, что числа не нарисованы

1. Откройте вкладку «Обзор» и нажмите «разобрать» у любого года — число раскладывается до формулы
   с указанием правила, по которому посчитано.
2. Сравните любое число на экране с одноимённой колонкой в `results/`: интерфейс и генератор
   выгрузок используют один и тот же движок.
3. Измените строку в `data/supply_sources.csv` и пересоберите: расчёт подхватит новый канал.
   Проверка описана в `results/extensibility_check.md`.
